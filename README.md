# Rural Water Well Monitoring System

This project is a web application for monitoring rural water wells. It consists of a Node.js/Express backend and a React/Vite frontend.

## ✨ Features

- **Backend**: Node.js, Express, MongoDB
- **Frontend**: React, TypeScript, Vite
- **Database**: MongoDB Atlas

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- MongoDB Atlas account (or local MongoDB instance)

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/dinuwa2500/rural-water-well-monitoring-system.git
    cd rural-water-well-monitoring-system
    ```

2.  **Install Backend Dependencies:**

    ```bash
    cd backend
    npm install
    ```

3.  **Install Frontend Dependencies:**

    ```bash
    cd ../frontend
    npm install
    ```

### Configuration

1.  **Backend:**
    - Create a `.env` file in the `backend` directory.
    - Add the following environment variables:

    ```env
    PORT=5000
    MONGO_URI=your_mongodb_connection_string
    ```

### Running the Application

1.  **Start the Backend:**

    ```bash
    cd backend
    npm run dev
    ```

2.  **Start the Frontend:**

    ```bash
    cd frontend
    npm run dev
    ```
